十六、成語整理

成語意思出處
光風霽月原指雨過天晴後的明淨景象；後比喻政治清明，時世太平的局面。第91課，補充
嶔崎磊落、冰壺秋月形容人品卓越不凡、心地光明高潔（與光風霽月同為形容雨後晴朗或品格高潔之詞）。第91課，補充
目光如炬①比喻見事透徹、識見遠大②形容目光有神。第91課，隨堂練習選項
高瞻遠矚站得高，看得遠；形容見識遠大。第91課，隨堂練習選項
未雨綢繆比喻事先預備，防患未然。第91課，隨堂練習選項
動輒得咎一有舉動就會犯過，受到責難，指人處境困難。第92課，補充
矜功伐善自誇功勞與優點（對照馮異的「謙退不伐」）。第92課
口誅筆伐用言語和文字揭發、譴責他人的罪狀。第92課，隨堂練習
狐假虎威比喻憑恃有權者的威勢恐嚇他人、作威作福。第93課
販夫走卒經營小本生意或替人跑腿的人，泛指生活在下階層的老百姓。第93課，補充
飛禽走獸泛指鳥類和獸類。第93課，補充
行屍走肉會走動卻沒有魂魄的軀體，比喻一個人徒具形骸，缺乏生氣，庸碌無為。第93課，補充
落荒而走戰敗後，離開大路逃向荒野；泛指倉皇逃跑。第93課，隨堂練習選項
郢書燕說比喻穿鑿附會，扭曲原意。第95課
詠絮之才（掃眉才子、不櫛進士）稱讚女子有文才。櫛，古人用來束髮的梳篦；不櫛進士形容有文才的女子。第96課，補充
差強人意大致還能使人滿意。第96課，補充
以訛傳訛訛，錯誤。指將不正確的訊息繼續傳播下去。第97課，補充
含沙射影傳說水中有一種叫蜮的怪物，能含沙噴射人影，使人得病；比喻暗中害人。第97課，補充
指桑罵槐指著桑樹罵槐樹，比喻拐彎抹角的罵人。第97課，補充
拾人牙慧牙慧，言談間流露出的智慧；比喻蹈襲他人的言論或主張。第97課，補充
人云亦云別人說什麼，自己也隨聲附和；形容沒有獨立的見解，只會盲從跟風。第97課，補充
尖嘴猴腮嘴巴尖，面頰瘦；常用來形容人長相不佳。第98課，成語教室
沐猴而冠猴子即使戴上帽子，也不像人；比喻人虛有儀表或地位，卻不脫膚淺粗鄙的本質。第98課，成語教室
殺雞儆猴殺隻雞給猴子看，使猴子害怕；比喻懲罰一個人，以警告另一個人。第98課，成語教室
螻蟻尚且偷生連螻蟻都愛惜生命，何況是萬物之靈的人；比喻人要愛惜生命，不可輕生。第98課，補充
以其人之道，還治其人之身就用那個人對付別人的方法來對付他本人。第98課，補充
兩腳書櫥比喻死讀書，不知活用的人。第99課，補充
食古不化學習古代知識卻不能充分理解、應用，如同吃了東西不能消化一樣；比喻一味守舊而不知變通。第99課，補充
刻舟求劍比喻拘泥固執，不知變通（複習頁32荊人涉澭、頁40鄭人買履）。第99課，補充
膠柱鼓瑟將瑟的弦柱黏住，鼓瑟時就不能調節音調的高低；比喻頑固而不知變通。第99課，補充
好高騖遠一味地嚮往高遠的目標而不切實際。第99課，隨堂練習選項

第91課　迂公修屋

詞語意思
迂公做事迂腐、拘泥不知變通的人
徙遷移、移轉
卒終於
謫指責、責罵
葺修補
良很
霽雨後轉晴
竟全部、整個
仰抬頭
折損失、喪失

原文：久雨屋漏，一夜數徙床，卒無乾處。妻兒交謫。迂公急呼匠葺治，勞費良苦。工畢，天忽開霽，竟月晴朗。公夕仰屋嘆曰：「命劣之人，才葺屋，便無雨，豈不白折了也！」

語譯：長時間下雨，屋頂開始漏水，整個晚上多次移動床位，最後家中再也沒有乾燥的地方了。妻子和小孩不斷責備他，迂公連忙請工匠來修補整建，辛辛苦苦耗費了許多勞力和金錢。房子整修好後，天氣突然轉晴，整個月天氣晴朗。迂公抬頭看著屋頂，嘆氣說：「我的命運真不好，屋子一修補好，就不再下雨了，這不是白白損失了修屋子的錢嗎？」

主旨：諷刺目光短淺、只計較自己得失，連天晴都當成損失的人。

補充：光風霽月：原指雨過天晴後的明淨景象，後比喻政治清明、時世太平的局面。

補充：「悉、舉、竟」（文言文）：全部、整個、全（比較頁7、11、94）。

補充：「折」：損失、喪失（賠了夫人又折兵）；其餘義項如彎曲（不為五斗米折腰）、挫敗（百折不撓）。

第92課　大樹將軍　《後漢書》

詞語意思
異馮異，東漢大將
伐自誇
輒每、總是
引退避
表識標幟、信號
舍住宿
屏退避
更更換、調整
隸分屬
光武漢光武帝劉秀
多稱讚

原文：異為人謙退不伐，行與諸將相逢，輒引車避道。進止皆有表識，軍中號為整齊。每所止舍，諸將並坐論功，異常獨屏樹下，軍中號曰「大樹將軍」。及破邯鄲，乃更部分諸將，各有配隸。軍士皆言願屬大樹將軍，光武以此多之。

語譯：馮異做人處事謙虛退讓，從不自我誇耀。出行與別的將軍相遇，就把馬車避開讓路。部隊前進停止都有標幟，所以軍中號稱最有紀律。每到一個地方停下來宿營，其他將軍坐在一起爭論功勞時，馮異常常獨自退避到樹下，部隊中稱他為「大樹將軍」。等到攻破邯鄲，重新調整所屬部隊，各有配屬。軍士都說希望分配到大樹將軍麾下，光武帝因此讚揚他。

主旨：馮異謙虛退讓、不居功自傲，因而受到士兵愛戴與君王稱許。

補充：伐：①自誇（不伐）②征討、攻打（口誅筆伐）。

補充：後人用「大樹將軍」來形容不居功自傲的將領。

補充：「願無伐善，無施勞」：不誇耀自己的優點，不表白自己的功勞。

第93課　狐假虎威　《戰國策》

詞語意思
求尋找
無敢不敢
長做首領
逆違逆
走逃跑
然對、正確
故因此
遂於是、就
皆全、都
子你（汝＝爾＝子＝若＝君）

原文：虎求百獸而食之，得狐。狐曰：「子無敢食我也！天帝使我長百獸，今子食我，是逆天帝命也。子以我為不信，吾為子先行，子隨我後，觀百獸之見我不走乎？」虎以為然，故遂與之行。獸見之皆走。虎不知獸畏己而走，以為畏狐也。

語譯：老虎捕捉各種動物來吃，抓到一隻狐狸。狐狸說：「你不敢吃我！天帝已命令我做百獸的首領，今天你如果吃了我，就是違逆天帝的命令。如果你認為我的話不可相信，我就走在前面，你跟在我後面，看看其他動物見到我有敢不逃跑的嗎？」老虎認為狐狸的話有道理，因此就跟在狐狸後面一塊前往。山林中的動物看到牠們都趕快逃走。老虎不知道所有動物是因為害怕自己才逃跑的，還以為牠們真的是怕狐狸。

主旨：狐狸藉老虎的威風嚇走百獸，卻使老虎誤以為百獸怕的是狐狸；後比喻憑恃有權者的威勢恐嚇他人。

補充：「走」：①逃跑（獸見之皆走、落荒而走）②在陸地上行動的，形（走獸）。

補充：販夫走卒、飛禽走獸、行屍走肉。

補充：「予＝余＝吾」我；「汝＝爾＝子＝若＝君」你；自謙「愚＝某＝僕」。

第94課　勤力惜時　《晉書》

詞語意思
侃陶侃，東晉時著名政治家、軍事家
州廣州
輒往往、總是
甓磚頭
齋書房
過爾過分
優逸安逸
堪承受、擔當
寸陰一寸光陰，指極短的時間
分陰一分光陰
無聞沒沒無名

原文：侃在州無事，輒朝運百甓於齋外，暮運於齋內。人問其故，答曰：「吾方致力中原，過爾優逸，恐不堪事。」其勵志勤力，皆此類也。常語人曰：「大禹聖人，乃惜寸陰；至於眾人，當惜分陰。豈可逸遊荒醉？生無益於時，死無聞於後，是自棄也！」

語譯：陶侃在廣州時，沒有事情的時候，總是早上把一百塊磚搬到書房外，晚上再搬到書房內。有人問他緣故，他回答：「我正在盡力收復中原，過分安逸享樂，恐怕將來不能承擔重任。」他勉勵自己、勤奮努力，都像這一類的事。他常對人說：「大禹這樣的聖人，尚且珍惜每一寸光陰；至於一般人，更應當珍惜每一分光陰。怎麼可以遊蕩玩樂、放縱沉醉呢？活著對時代沒有益處，死了後世也沒有人知道，這是自暴自棄啊！」

主旨：陶侃自我磨練、勤奮不懈，並勉勵人惜時奮發，不可自暴自棄。

補充：恐：擔心（恐不堪事＝擔心無法承擔重任）。

補充：輒：往往、總是（副詞）。

補充：可與第81課「陶母責子」對照，同為陶侃的故事。

第95課　郢書燕說　《韓非子》

詞語意思
郢春秋時楚國的都城
遺贈送、給予
燕燕國
書①寫，動詞　②書信，名詞
云說
過錯誤
說解釋
尚崇尚
舉選拔
任任用
白報告

原文：郢人有遺燕相國書者，夜書，火不明，因謂持燭者曰：「舉燭。」云而過書「舉燭」。「舉燭」，非書意也。燕相受書而說之，曰：「『舉燭』者，尚明也；尚明也者，舉賢而任之。」燕相白王，王大悅，國以治。治則治矣，非書意也。

語譯：楚國郢都有個人寫信給燕國的相國，他在晚上寫信，燈火不夠明亮，便對拿著蠟燭的人說：「把蠟燭舉高一點。」邊說邊不小心把「舉燭」寫到了信裡。「舉燭」並不是信裡應有的意思。燕國相國收到信之後，解釋信中的內容說：「『舉燭』是要崇尚光明；崇尚光明的意思，就是要選拔賢能的人來任用。」燕相把這個想法報告燕王，燕王非常高興，國家因此得到治理。治理是治理好了，可是並不是原信的本意啊。

主旨：燕相誤解信中「舉燭」二字而歪打正著；後比喻穿鑿附會，扭曲原意。

補充：郢書燕說：後比喻穿鑿附會，扭曲原意。

補充：「書」字：寫（動詞）、書信（名詞）。

補充：「說」：解釋，不是「悅」；「王大悅」的「悅」才是喜悅。

第97課　穿井得人　《呂氏春秋》

詞語意思
溉灌注、澆水
汲自井中取水
穿開鑿
一人一個人的勞力
聞聽到
傳傳播、流傳
道談論
使功用、勞力
一人（井中）一個真的人
對回答

原文：宋之丁氏，家無井而出溉汲，常一人居外。及其家穿井，告人曰：「吾穿井得一人。」有聞而傳之者曰：「丁氏穿井得一人。」國人道之，聞之於宋君。宋君令人問之於丁氏。丁氏對曰：「得一人之使，非得一人於井中也。」

語譯：宋國有一戶丁姓人家，家裡沒有水井，要外出取水回來灌溉土地，因此常用掉一個人的勞力在外頭。後來他在家中開鑿了一口井，告訴別人說：「我們家開鑿一口井後，得到了一個人的勞力。」聽到這個說法的人又傳播出去說：「丁家開鑿了一口井，挖出一個真的人。」國都裡的人都在談論這件事，後來傳到了宋國國君耳裡。宋君派人向丁家詢問這件事，丁家人回答說：「是多出一個人的勞力，而不是從井裡挖出一個人來。」

主旨：傳聞容易失真，凡事不可輕信流言，要查證求實。

補充：以訛傳訛、人云亦云、拾人牙慧、含沙射影、指桑罵槐。

補充：「一人」有兩義：一個人的勞力／一個真的人。

補充：「予＝余＝吾」我；自謙「愚＝某＝僕」。

    假（ㄐㄧㄚˇ）：形容詞，不真的、虛偽的。
  4. 「狐『假』虎威」的「假」，意思是？
    假：動詞，借；狐狸借老虎的威風。
  5. 「斯七子者，於學無所遺，於辭無所『假』」的「假」，意思是？
    假：動詞，依傍；寫作時不必依傍別人。
  6. 「不以為『然』」的「然」，意思是？
    然：形容詞，對、正確；不以為然＝不認為對。
  7. 「斐『然』成章」的「然」，意思是？
    然：詞尾，助詞，斐然＝有文采的樣子。
  8. 「自古皆『然』」的「然」，意思是？
    然：代詞，如此。
  9. 「明知『故』犯」的「故」，意思是？
    故：副詞，有意地、存心地。
  10. 「溫『故』知新」的「故」，意思是？
    故：名詞，已學得的知識。
  11. 「『撤』職」的「撤」，意思是？
    撤（ㄔㄜˋ）：除去、免去。
  12. 「『散』播」的「散」（ㄙㄢˋ），意思是？
    散（ㄙㄢˋ）：分布、撒出；不自約束、零碎、閒逸的讀ㄙㄢˇ。
  13. 「『差』強人意」的「差」（ㄔㄚ），意思是？
    差：副詞，尚、略、還。
  14. 「『為』人作嫁」的「為」（ㄨㄟˋ），意思是？
    為（ㄨㄟˋ）：介詞，替。
  15. 「二蟲盡『為』所吞」的「為」（ㄨㄟˊ），意思是？
    為（ㄨㄟˊ）：介詞，被。

貳、成語練習

  1. 「光風霽月」後來比喻？
    光風霽月：原指雨過天晴後的明淨景象，後比喻政治清明、時世太平。
  2. 「狐假虎威」比喻？
    狐假虎威：借老虎的威風嚇人。
  3. 丁氏「穿井得一人」被說成「穿井得到一個人」，這種現象可以說是？
    以訛傳訛：將不正確的訊息繼續傳播下去。
  4. 「人云亦云」形容的是？
    人云亦云：別人說什麼自己也跟著說。
  5. 「食古不化」的意思是？
    食古不化：如同吃了東西不能消化。
  6. 「未雨綢繆」比喻？
    未雨綢繆：趁著還沒下雨，先修補門窗，比喻事先預備，防患未然。

參、課文選擇題

第91課　迂公修屋

  1. 迂公「一夜數徙床」是因為？
    久雨屋漏，卒無乾處。
  2. 「竟月晴朗」的「竟」，意思是？
    竟：副詞，整個、全（文言文）。
  3. 從本文可以看出，迂公是個怎樣的人？
    把天晴當成修屋的損失，只計較眼前得失。
  4. 下列哪一個「折」，意近於「豈不白折了也」的「折」？
    白折＝白白損失；賠了夫人又折兵的「折」也是損失。

第92課　大樹將軍

  1. 「馮異為人謙退不伐」的「伐」，意近下列哪一個？
    不伐＝不自誇；矜功伐善的「伐」也是自誇。
  2. 諸將並坐論功時，馮異為什麼「常獨屏樹下」？
    馮異謙退不伐，不爭功勞。
  3. 軍士為什麼「皆言願屬大樹將軍」？
    馮異謙退有紀律，深受愛戴。
  4. 「行與諸將相逢，輒引車避道」的「輒」，意思是？
    輒：每、總是。

第93課　狐假虎威

  1. 狐狸要老虎不要吃牠的理由是？
    天帝使我長百獸，今子食我，是逆天帝命也。
  2. 「觀百獸之見我不走乎」的「走」，意近於下列哪一個「走」？
    此處的「走」＝逃跑；落荒而走也是逃跑。
  3. 「獸見之皆走」，百獸真正害怕的是？
    百獸怕的是老虎，老虎卻誤以為牠們怕狐狸。
  4. 「虎以為然」的「然」，意思是？
    然：形容詞，對、正確。

第94課　勤力惜時

  1. 陶侃每天朝運百甓於齋外、暮運於齋內，目的是？
    為了不過分安逸，才能承擔收復中原的重任。
  2. 「恐不堪事」的意思是？
    恐＝擔心；不堪事＝承擔不了重任。
  3. 「大禹聖人，乃惜寸陰；至於眾人，當惜分陰」是在勉人？
    聖人尚且惜寸陰，何況眾人。
  4. 「生無益於時，死無聞於後，是自棄也」是提醒人要？
    勉人不可自暴自棄，要奮發向上。

第95課　郢書燕說

  1. 郢人為何在信中寫下「舉燭」兩字？
    邊說邊不小心把「舉燭」寫進信裡。
  2. 文中燕國大治是因為？
    燕相把「舉燭」解釋為尚明任賢，國家因此治理。
  3. 下列「書」字的詞性說明，何者不正確？
    「燕相受書」的「書」是書信，名詞。
  4. 後人用「郢書燕說」來形容？
    郢書燕說：穿鑿附會，扭曲原意。

第96課　詠絮才女

  1. 本文主旨是？
    謝道韞以「柳絮因風起」比喻雪，獲得謝安稱許。
  2. 「撒鹽空中差可擬」的「差」，意思是？
    差可擬＝勉強可以比擬；差（ㄔㄚ）＝尚、略、還。
  3. 有關本文的分析，下列哪一項不正確？
    謝安以「未若」肯定道韞的比喻更好，兩人並非不分高下。
  4. 後人以「詠絮才」來形容？
    詠絮之才：稱讚女子有文才。

第97課　穿井得人

  1. 本文的主旨是？
    丁氏的話經人轉述，竟變成「挖出一個人」。
  2. 丁氏為什麼說「吾穿井得一人」？
    得一人之使＝得到一個人的勞力。
  3. 「宋君令人問之於丁氏」，是去問什麼？
    問「穿井得一人」的傳聞是否屬實。
  4. 「有聞而傳之者曰：『丁氏穿井得一人』」的行為可以說是？
    把話傳錯，又繼續傳播＝以訛傳訛。

第98課　吳王射狙

  1. 吳王登上狙之山，眾狙見到他，反應是？
    恂然棄而走，逃於深蓁。
  2. 「見巧乎王」的意思是？
    見：顯露、展示；見巧＝賣弄靈巧。
  3. 那隻賣弄靈巧的獼猴，下場是？
    吳王一箭被牠接住，再命相者趨射，狙執死。
  4. 本文的寓意是？
    狙因炫耀靈巧而被射死。

第99課　蠹魚蝕書

  1. 本文主旨是？
    滿腹詩書卻食而不化。
  2. 蠹魚「忿」的原因是？
    自命通儒，卻被蜣螂欺、被蠅虎傷。
  3. 「遂昂頭天外，有不可一世之想」表現出蠹魚？
    不可一世＝自認為當代沒有人比得上。
  4. 人說蠹魚「奈皆食而不化者」，是在嘲笑牠？
    書讀得多卻無法消化運用＝食古不化。

第100課　晏子逐高繚

  1. 下列「　」中的字，哪一個不是指「晏子」？
    「今此子」指高繚，其餘皆指晏子。
  2. 晏子認為自己是怎麼樣的人？
    嬰仄陋之人也，四維之然後能直。
  3. 高繚被晏子辭退的原因是？
    未嘗弼吾過，是以逐之也。
  4. 根據本文，晏子希望任用的是什麼樣的人？
    希望有人能直言糾正自己的過錯。
